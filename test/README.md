# Data Provenance and Versioning

  

This master’s thesis uses data from the **UD_Nheengatu-CompLin** treebank.

To ensure transparency and reproducibility, the exact version of the data used in the experiments is documented below.

  

## Source Repository

  

- Repository: [UD_Nheengatu-CompLin](https://github.com/CompLin/nheengatu)

- Files used:

-  `yrl_complin-ud-train.conllu`

-  `yrl_complin-ud-test.conllu`

  

The file `all.conllu` was generated locally by combining the training and test files.
